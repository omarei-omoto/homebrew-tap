# omarei-omoto/tap

Homebrew formulae for [hush](https://github.com/omarei-omoto/hush): team secrets your AI agent can use but never read.

```bash
brew install omarei-omoto/tap/hush
```

`Formula/hush.rb` is generated by hush's release workflow for each tag, and points at that release's binaries by sha256. Don't edit it by hand; it is replaced on the next release.
